TechBairro 3.3.1

Como executar
1. Abra um terminal nesta pasta.
2. Execute: python techbairro.py

O banco techbairro.db será criado automaticamente na primeira execução.

Histórico do código
O projeto usa Git. Para ver o histórico, execute na pasta do projeto:
git log --oneline
