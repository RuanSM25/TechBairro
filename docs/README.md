# TechBairro 3.3.1

O projeto foi separado em arquivos para organizar melhor o código:

- `techbairro.py`: tela principal do programa.
- `cliente.py`: representa os dados de um cliente.
- `banco.py`: cuida do banco de dados.
- `validacao.py`: confere os dados informados.
- `scripts/`: reúne scripts auxiliares.
